# Personal Library Manager 📚

A Python application to manage your personal book collection with advanced features.

## ✨ Features
- ➕ Add books with details (title, author, year, genre, status)
- 👀 View all books in a formatted list
- 🗑️ Remove books from your collection
- 🔍 Search books by title, author, or genre
- 📊 Count total books
- 💾 Save and load your library automatically
## 🛠️ Technologies Used
- Python 3
- JSON for data storage
- File handling
